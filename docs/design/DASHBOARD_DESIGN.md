# Dashboard design contract

The supplied PNG is the binding visual reference. The implementation preserves its light Home Assistant visual language, six-tab navigation, rounded KPI cards, restrained blue/teal accents, charts, compact tables, and responsive single-column mobile layout.

Every value in the PNG is illustrative. The shipped panel displays only validated database records. House Thermal Profile, COP & Efficiency, and Forecasts show honest roadmap states until their required measurements and models are implemented.
